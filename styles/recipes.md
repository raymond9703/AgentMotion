# 15 种商用级纯代码风格配方

> 每条配方 = 调色板 / 核心技法 / 运动规律 / 避坑。全部可用 Canvas 或 Remotion 实现。
> 灵感源自社区对「Claude Opus 5.5 十五种 MG 风格」展示片的观察与再创作；配方代码均为本项目原创。

## 01 逐帧手绘 Frame-by-Frame
- **调色板**：纸黄底 `#F5EBD8` + 大红 `#D93A2B` + 墨黑线条，色块外一圈白边
- **技法**：所有轮廓走沸腾线（种子每 4 帧一换）；色块用带噪点的填充（随机小点覆盖，透明度 0.06）；关键动作拍两帧（"一拍二"，8-12 个关键循环）
- **运动**：角色动作遵循 anticipate → snap → settle；火苗/头发等持续元素做 3-4 帧小循环
- **避坑**：沸腾 ≠ 抖动；一拍二比逐帧更"手绘"；纸纹理要静态（噪声不随时间滚动）

## 02 等轴 2.5D Isometric
- **调色板**：单色系三阶（顶亮 `#5FB4E8` / 侧中 `#3E8FC4` / 暗面 `#2A6A96`）+ 深底
- **技法**：投影 `(col-row)*T/2, (col+row)*T/4`；每块三面（顶/左/右）明度固定分档；光线方向全片不变
- **运动**：层自下而上 stagger 进入（back.out，0.12s 间隔）；爆炸图沿 Z 轴整体开合；相机漂移 < 几度
- **避坑**：平行投影禁透视缩放；沿 translateZ 抬升而非 scale 放大

## 03 扁平矢量 Flat Vector
- **调色板**：≤4 色高饱和（如克莱因蓝底 + 珊瑚红主体 + 米白地面），零渐变
- **技法**：纯几何（圆/胶囊/圆角矩形）；零阴影或纯色零偏移阴影；运动沿弧线不沿直线
- **运动**：回弹（outBack 1.5-2.0）讲一切故事：落地弹起、果冻挤压、节拍点头
- **避坑**：缓动即人设——同一支片统一一种弹性系数；圆形运动的弧线要用二次贝塞尔显式画

## 04 线条动画 Line Art
- **调色板**：单色线（黑/金/白）+ 大面积留白底
- **技法**：`stroke-dashoffset` 或逐段贝塞尔手画；单线轮廓 + 少量填充点缀；线宽 2-4px 统一
- **运动**：线在 0.8-1.2s 内匀速画出（ease-in-out 会"抽搐"）；关键帧间用形变插值
- **避坑**：交叉线先画长的；闭合形状先轮廓后填充淡入；线宽随镜头 zoom 缩放保持视觉恒定

## 05 3D 渲染 3D Render
- **调色板**：低饱和环境 + 一个高饱和主角色（粉字落进米白珠海）
- **技法**：Three.js（页面内）或 Blender+Cycles（离线出帧序列再喂 ffmpeg）；网格阵列 + 置物即景
- **运动**：物理弹跳（弹簧模拟）、软体挤压、景深呼吸
- **避坑**：页内 three.js 必须确定性——固定随机种子、禁 rAF 物理（用解析式 t 的函数代替积分）

## 06 形变动画 Morphing
- **调色板**：前后形态共享一套 3-4 色
- **技法**：顶点数相同的两个路径 lerp（Canvas 手动插值）；或 SVG path morph；保持面积守恒避免"缩没"
- **运动**：crossfade + 顶点插值混合（0.4-0.6s）；中途加一点 overshoot
- **避坑**：顶点要预先对齐起点（最短路径匹配）；文字↔图形形变先统一为轮廓点集

## 07 贴纸风科普 Sticker Explainer
- **调色板**：深灰板面 `#2E3238` + 贴纸白边 + 一个强调橙红
- **技法**：粗白描边（6-10px）+ 微阴影 = 贴纸感；超大自然数字（视口高 40%+）；元素像贴上去的——进场贴纸 slams（scale 1.15→1 + 轻旋 ±3°）
- **运动**：一次只贴一张；讲到的元素高亮、其余压暗到 0.35 透明度
- **避坑**：这是信息设计——先定"一屏一句话"；数字用 tabular-nums 防抖

## 08 赛博朋克 HUD
- **调色板**：近黑底 + 青色 `#00E5FF` + 品红点缀 + 荧光绿数据
- **技法**：扫描线（每 3px 一条 0.04 透明度暗线）、角框（只画四角括号）、网格地平线、等宽字体数据流
- **运动**：数据滚动 + 随机 glitch（每 2-4s 一次 RGB 分离 2-3 帧）；雷达扫掠扇形
- **避坑**：glitch 是调味不是主食；所有闪烁幅度 ≤0.15 透明度防频闪不适

## 09 拼贴剪贴 Collage
- **调色板**：牛皮纸/新闻纸底纹 + 3-4 个印刷色块
- **技法**：形状边缘做撕纸锯齿（多边形 + 抖动顶点）；元素带轻微随机旋转（±6°）与纸投影；"照片"用纯色 + 颗粒模拟
- **运动**：元素像被手摆上去——落下 → 微弹 → 下一张；偶尔整张滑走换版
- **避坑**：旋转角度用种子随机固定住，不要每帧重摇；层次靠投影不靠描边

## 10 玻璃拟态 Glassmorphism
- **调色板**：鲜艳渐变底 + 白色半透明面板（`rgba(255,255,255,.15)` + `backdrop-blur`）
- **技法**：Canvas 模拟磨砂 = 底图先画 → 截取区域 `filter: blur(20px)` 重画 + 白描边 1px（上亮下暗）；高光斜线扫过
- **运动**：面板滑入带轻微弹性；内容错落 stagger；高光每 4-6s 扫一次
- **避坑**：文字对比度——玻璃上文字加 0.6 透明度白底垫层；blur 很贵，背景 blur 区域预渲染

## 11 包豪斯几何 Bauhaus
- **调色板**：米白纸底 `#EDE6D6` + 红黄蓝黑四原色，无第五色
- **技法**：严格网格（120px）；圆/方/三角三原形；细十字定位线与角标（图纸感）；大字几何无衬线
- **运动**：120 BPM 整拍运动——元素按拍滑入、旋转 90°、翻转；一页海报 20 拍搭完
- **避坑**：克制即风格——禁缓动弹性（用 linear/inOutCubic）；每屏 ≤3 个原色形状

## 12 Synthwave 复古
- **调色板**：深紫夜空 `#1A0B3D` + 品红地平线 + 青色霓虹描边 + 落日渐变橙
- **技法**：透视网格地面（向灭点滚动的横线，速度恒定）；霓虹 = 多层描边（外发光 + 内亮线）；太阳条纹遮挡
- **运动**：网格恒速滚动制造"前进感"；霓虹灯 2-3 帧随机闪烁（模拟灯管坏点）
- **避坑**：渐变每帧重算很贵 → 预渲染背景层；文字用倾斜 8° 斜切制造速度感

## 13 像素风 Pixel Art
- **调色板**：固定 16-32 色调色板（先定义数组，全片只用这些色）
- **技法**：低分辨率离屏 canvas（如 480×270）绘制 → `imageSmoothingEnabled=false` 放大 4×；角色 3-4 帧行走循环；抖动(dither)过渡大面积色块
- **运动**：整像素移动（坐标取整），半像素会糊；帧动画一拍二（12fps 有效帧率）
- **避坑**：文字也用像素字（自绘 5×7 点阵或内置像素字体位图）；调色板一旦定下不许加色

## 14 液态流动 Liquid Motion
- **调色板**：深底 + 双色液滴（紫橙渐变或同色系深浅）
- **技法**：metaball（SDF：多圆势场叠加 + 阈值轮廓，Canvas 用径向渐变叠加近似）；高光点固定在光源方向；拉丝 = 两球连线加密采样
- **运动**：落下加速 → 撞击压扁 → 涟漪扩散 → 融合（两球靠近时 lerp 合并）；表面张力感 = 轮廓平滑
- **避坑**：液滴永不静止——idle 时做微呼吸；波纹必须椭圆压扁（正圆波纹在地面上不成立）

## 15 综艺花字 Variety Show Lettering
- **调色板**：纯色底 + 高饱和花字（黄字红边白描边 + 投影）
- **技法**：字必须"立起来"：粗描边（≥ 字号 8%）+ 硬投影 + 微倾斜；强调词放大 1.3× + 换色；拟声词（砰！/叮！）单独成卡
- **运动**：花字 slam 进场（1.2→0.96→1.0 两帧回弹）+ 定住 1-1.5s + 弹出；关键词逐字蹦出（stagger 60ms）
- **避坑**：花字是信息层级不是装饰——每屏最多一句；描边色从底色补色环取，保证任何底色上都可读
