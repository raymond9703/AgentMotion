# 配乐与音画对齐

## 三种来源

1. **代码合成（默认）**：`window.SCORE = ac => { ... }`（Web Audio / OfflineAudioContext 离线渲染成 WAV 混入 MP4）。鼓、拨弦、pad、铃铛都能写；管弦与人声不行（改用 2/3）。
2. **AI 生成音乐**（用户要求时）
3. **用户自己的曲目**：`--audio file.mp3` 直接混流；此时**画面服从音乐**——渲染后测切点偏移，把 SHOTS 的边界挪到实测节拍上重渲（镜头函数都接收镜头内局部时间，挪边界不碰镜头代码）。

## 音乐跟画面的规则（防"惊吓切点"）

- **速度表**：每段整数小节，切点自然落在强拍
- **切点用和声标记，不用音量**：段尾走向属和弦、切点回到主和弦；切点上的响度跳变 **≤+6dB**（实测 +7~+10dB 会被感知为 jump scare；+3~+5dB + 换和弦 = 干净的剪辑感）
- 切点小节**不加额外重音**（连正常强拍重音都省掉——前一小节正在衰减）
- 分层乐器**每小节最多进 1-2 层**（齐进实测 +11dB；错开一小节 +3.5dB）
- 片内硬切也进 `CUES`，享受同样的强拍待遇
- **留白 Break**：高潮前整小节静默，是最强的节拍；切入静默算落在拍上

## 校验

```bash
node scripts/render.mjs film.html out.mp4        # 生成 out.cues.json（来自 window.CUES）
# 切点检测：对每个 CUE 找最近强音频起振，报偏移与响度跳变
# 失败标准：OFF-BEAT >±100ms 或 STARTLE >+6dB —— 修到全绿或能点名"这是故意的 stinger"
```

无声 MP4 也合法（用户只要画面时），但交付时提一句可加配乐。
