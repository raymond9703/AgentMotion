# 工作流总览

## 一图流

```
读题 → 选后端 → 选风格 → 分镜(BPM/SECTIONS/SHOTS/EVENTS) → 骨架搭建
     → 静帧自检(分镜符合度) → contact sheet 导演轮 → 修 → 全片渲染 → probe → 交付
```

关键纪律：**自检在渲染之前，静帧在全片之前**。改哪帧只重渲哪帧。

## 片型 → 默认参数

| 片型 | 默认时长 | 画幅 | 后端 | 参考风格 |
|---|---|---|---|---|
| 故事/绘本短片 | 15-20s | 1920×1080 | Canvas | 逐帧手绘、水彩、线条 |
| 科普讲解 | 30-90s | 1920×1080 | Canvas 或 Remotion | 贴纸科普、白板、图表 |
| 产品/宣传 | 15-30s | 1920×1080 | Remotion | 扁平矢量、玻璃拟态、3D |
| 数据盘点/Wrapped | 20-25s | 1080×1920 | Remotion | 大数字、榜单、超立方 |
| 风格目录/盘点片 | 每章 ~11s | 1920×1080 | Canvas | 卡片版式 + 多风格混排 |
| 无缝循环/GIF | 2-4s | 任意 | Canvas | 像素、Synthwave、液态 |

## 读题清单（一次问清，不中途停）

1. 主题一句话 + 受众是谁
2. 有没有外部素材（图/音频/数据表）→ 决定后端
3. 有没有指定风格 → 没有就按主题推荐 2 个备选
4. 时长与画幅没有说 → 用上表默认值，交付时说明可改

## 分镜先行

画面与配乐读同一份时间数据（`SECTIONS`/`SHOTS`/`EVENTS`），音画天然对齐。
写分镜时核对因果链：每个节拍由上一个节拍引起，隐喻在画面里可见。
详见 `storyboard.md`。

## 交付

- MP4（h264，yuv420p，能直接发社交平台）
- HTML 源文件（浏览器可直接播放，是"源码版成片"）
- 结尾一两句提供可变更项：换风格 / AI 配乐或用户曲目 / 改时长
