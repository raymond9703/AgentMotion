# 分镜：节拍网格 · 镜头表 · 调度

分镜是数据，不是散文。三张表写进页面，画面和配乐都读它们：

```js
const BPM = 96;
const SECTIONS = [{ name, start /* beat */, bars }];   // 每段整数小节 → 切点必在强拍
const SHOTS = [{ t0, t1, cam, world, event }];          // 帧区间 + 相机 + 内容 + 落点
const EVENTS = [{ frame, name }];                       // 所有切点 + 片内重音（供 sync-check）
```

## 节拍网格（先于一切画面）

1. 定 BPM（96 慢叙事 / 120 标准 / 140 快节奏盘点）。
2. 每段给**整数个小节**（4 拍/小节）→ 每个切点自动落在强拍上。
3. 段落总时长 = Σ(bars × 4) / (BPM/60) 秒。帧数 = 秒 × fps。

## 镜头表节奏参考

| 片型 | 单镜头时长 | 每章/每景子镜头 |
|---|---|---|
| 故事 | 3-6s | 1 个动作 + 1 个反应 |
| 讲解 | 4-8s | 一句话一个画面 |
| 盘点/目录 | 10-11s | 2-3 个子镜头 |
| 数据片 | 2.5-4s/场景 | 一屏一个数字 |

## Blocking（连续世界的故事/讲解）

一个连续的世界，镜头在其中移动。列出每个镜头的 **reads**——观众此刻必须理解的事：
- 一次只给一个 read；快动作、长停留
- reads 决定镜头长度，不是反过来
- 每个动作有因果（前镜头引起），每个伏笔有回收
