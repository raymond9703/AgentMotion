这是什么

AgentMotion 是一个面向 AI Agent 的纯代码视频生成框架：让大模型用代码逐帧绘制并渲染出真正的 MP4——不生成素材、不调用扩散视频模型。每一帧都是帧号的纯函数 frame = f(t)，完全确定性：可自检、可并行、可复现。

核心能力

双渲染后端

零素材单文件 Canvas（默认）+ React/Remotion（数据驱动、批量个性化、烧录字幕）。

15 种商用级风格

逐帧手绘 / 等轴 2.5D / 扁平矢量 / 线条 / 3D / 形变 / 贴纸科普 / 赛博 HUD / 拼贴 / 玻璃拟态 / 包豪斯 / Synthwave / 像素 / 液态 / 综艺花字。

确定性渲染器

一条命令出 MP4 / 指定时刻静帧 / contact sheet，多 worker 并行出帧。

音画同源

画面与配乐读同一份时间数据，切点天然落在节拍上。

宿主无关

既是 Agent Skill，也可被任意有 shell 的 Agent 调用，人也能当 CLI 用。

开源（MIT）

所有代码与文档原创，零素材承诺，欢迎 PR。

15 种风格一览

快速开始

# 环境体检（Node 18+ / ffmpeg / Chrome 或 Edge）
node scripts/env-check.mjs
npm i playwright-core

# 跑通最小示例（8 秒）
node scripts/render.mjs examples/hello-drop.html sheet.jpg --sheet 1
node scripts/render.mjs examples/hello-drop.html out.mp4

# 做你自己的片
cp templates/starter.html my-film.html
node scripts/render.mjs my-film.html preview.mp4 --workers 6
node scripts/probe.mjs preview.mp4 1920x1080 30
